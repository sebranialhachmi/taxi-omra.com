# 01 · Per-Competitor Teardown

Each competitor is scored across the 32 dimensions required by the spec. Scores use 1–10 (10 = best-in-class KSA taxi/transport). Observations are directional and reflect the public-facing sites as of the audit date; a re-scan is scheduled quarterly.

**Dimensions (columns in each profile):**
Business Model · Homepage · Navigation · Services · Cities Covered · Airport Services · Routes · Booking Process · Design · Typography · Colors · Trust Signals · CTAs · WhatsApp Usage · Phone Usage · Internal Linking · SEO Structure · Technical SEO · Schema · Core Web Vitals · Content Quality · URL Structure · Metadata · Images · Blog · Footer · Mobile Experience · Page Speed · Conversion Funnel · Weaknesses · Strengths · Missing Opportunities.

## Set-wide observations

- **Universal gaps:** deep JSON-LD (only LocalBusiness where present), programmatic route pages, per-terminal airport pages, reciprocal hreflang, bilingual parity, editorial content.
- **Universal strengths:** sticky WhatsApp is table stakes; luxury/dark palettes dominate.
- **Weakest axes across the set:** Blog, Schema depth, Routes, Internal Linking, Content Quality.
